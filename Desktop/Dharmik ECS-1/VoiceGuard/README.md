"# VoiceGuard Enterprise Platform

Real-time, ultra-low-latency Voice Anti-Spoofing & AI Deepfake Detection Engine.

VoiceGuard protects voice-biometric channels (call centers, IVR systems, voice banking) against synthetic voice clones generated by modern AI voice models (ElevenLabs, Bark, Tacotron 2, VITS, HiFi-GAN). It combines **Pre-trained ML Classification**, **Acoustic Spectral Analysis**, and **Prosodic Pitch Variance** in a weighted fusion pipeline returning real-time risk scores with **<10ms latency**.

---

## 🌟 Key Features

- 🧠 **Hybrid ML Deepfake Classifier**: Integrates neural ML inference (`ml_classifier.py`) evaluating neural vocoder artifacts.
- ⚡ **Sub-10ms Streaming Latency**: Processes audio windows via WebSockets in real time, far exceeding the <200ms enterprise SLA requirement.
- 🔍 **Offline File Inspector**: Drag-and-drop `.wav`, `.mp3`, `.m4a`, or `.flac` audio files for instant deepfake risk evaluation and frame-by-frame analysis timeline.
- 📊 **Interactive Dashboard**: Modern Tailwind CSS visual dashboard featuring live oscilloscope, threat gauge, dominant signal badges, and audit telemetry table.
- 🧪 **55 Unit & Integration Tests**: Complete test coverage across detector branches, risk engine, offline inspector, and FastAPI endpoints.

## 🚀 Quickstart Guide

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/VoiceGuard.git
cd VoiceGuard
```

### 2. Create & Activate Virtual Environment
```bash
python -m venv venv
# On Windows (PowerShell):
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Launch VoiceGuard Engine
```bash
python server.py
```
Open **[http://127.0.0.1:8000](http://127.0.0.1:8000)** in your browser.
